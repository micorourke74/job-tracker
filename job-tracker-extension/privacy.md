# Job Tracker Clipper Privacy Policy

Job Tracker Clipper helps users save job listing details from the active browser tab into the Job Tracker web app.

## What the extension does

When the user clicks “Save this job,” the extension reads the currently active job listing page and attempts to extract job-related details such as job title, company name, location, pay range, work type, source, job listing URL, and description when available.

The extension does not run continuously in the background and does not monitor browsing activity.

## Data collection

Job Tracker Clipper does not collect, sell, or share user data with the developer or third parties.

The extension does not collect authentication information, personal communications, precise location, web history, or user activity tracking data.

## How job listing data is used

Any extracted job listing details are used only to open the Job Tracker web app with the job information ready for the user to review and save.

The Job Tracker app stores saved job entries locally in the user's browser unless the user chooses to export their own CSV backup.

## Remote code

Job Tracker Clipper does not execute remote code. All extension code is included in the submitted extension package.

# Search Specification

## Geography

Priority:
1. Remote - United States
2. Orlando, Florida
3. Hybrid within practical commuting distance of Orlando
4. Exceptional relocation roles only when relocation is explicitly viable

## Core target titles

- IT Support Specialist
- Help Desk Technician
- Help Desk Analyst
- Service Desk Analyst
- Technical Support Specialist
- Product Support Specialist
- SaaS Support Specialist
- Desktop Support Technician
- Application Support Analyst
- Junior IT Analyst
- IT Operations Analyst
- QA Tester
- Software Tester
- Quality Assurance Analyst
- Technical Support Analyst
- AI Support Specialist
- AI Operations Analyst
- AI Trainer / Evaluator
- Junior Automation Specialist

## Expansion titles

Use when the posting's actual duties match the candidate profile:
- Customer Support Engineer
- Support Engineer
- Implementation Support
- Technical Customer Success
- Systems Support
- IT Coordinator
- Technology Support
- Operations Support Analyst

## Hard rejects

Reject unless explicitly overridden:
- Senior / Staff / Principal / Lead / Director / VP
- Mandatory active security clearance not already held
- Mandatory 5+ years specialized engineering experience
- Commission-only work
- Unpaid roles
- Obvious MLM / recruiting schemes
- Jobs requiring residency outside viable geography
- Roles materially unrelated to IT, support, QA, applications, automation, or AI operations
- Postings with strong scam indicators
- Roles whose mandatory credential requirement is not met

## Preferred signals

Boost:
- Entry level / associate / junior
- CompTIA A+ recognized
- B.A. / A.S. in IT accepted
- Windows / Microsoft 365
- Ticketing / ServiceNow-style workflows
- Networking fundamentals
- Customer-facing technical support
- SaaS / product troubleshooting
- Documentation / knowledge-base work
- QA / testing
- AI-tool fluency
- Disney / hospitality technology adjacency

## Recency

Prefer jobs posted in the last 72 hours.
Strong matches older than 72 hours remain valid when still open.

## Source priority

1. Employer careers site
2. Employer ATS
3. Reputable job board
4. Recruiter/staffing posting with identifiable client or credible firm

When the same requisition appears in multiple places, keep one canonical record.

# Career Automation

This directory defines the operating system for Michael O'Rourke's job search automation.

## Goal

Maximize legitimate interview opportunities while minimizing manual effort.

The system is designed around:

1. Discover current openings.
2. Filter aggressively for realistic fit.
3. Score and prioritize.
4. Tailor application materials truthfully.
5. Complete application steps where permitted.
6. Escalate only for legal attestations, authentication, CAPTCHAs, signatures, or unknown personal facts.
7. Track outcomes.
8. Continuously improve targeting and resume variants from conversion data.

## Safety / quality rules

- Never fabricate experience, dates, credentials, clearances, education, tools, or accomplishments.
- Never bypass CAPTCHAs or anti-bot controls.
- Never answer legal or demographic self-identification questions without an approved standing answer.
- Never apply twice to the same requisition.
- Prefer official employer career pages over reposts when possible.
- Do not store PII, resume files, passwords, legal answers, or sensitive application data in this public repository.
- Stop automatic submission when a source-of-truth field is uncertain.

## Priority lanes

4. QA / software testing
